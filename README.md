### 👨‍💻 Sobre mí

¡Hola! Soy **Matías D'Agostino** (Tato), desarrollador Full-Stack de Paraná, Entre Ríos, Argentina 🇦🇷. Me gusta construir productos web y apps que sean sólidos, lindos y fáciles de usar.

- 🎓 **Formación:** Técnico Universitario en Programación (**UTN**).
- 🚀 **Ahora:** construyendo **Teire**, una app gratis para organizar tu día y compartirlo con amigos (Tauri + Supabase).
- 🛠️ **Stack principal:** **Java**, **Spring Boot**, **Python**, **FastAPI**, **TypeScript**, **React** y **Tailwind CSS**.
- 📊 **Explorando:** análisis de datos con **R** y bots de Discord.
- 💼 **Disponible:** proyectos colaborativos y desarrollo a medida como freelance.
