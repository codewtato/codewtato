### 👨‍💻 Sobre mí

Soy **Matías D'Agostino**, pero todos me dicen **Tato**. Soy Técnico Universitario en Programación (**UTN**) y me gusta construir cosas que se usen de verdad: APIs sólidas, interfaces prolijas y apps que le simplifiquen el día a alguien.

- 🚀 **Construyendo:** **Teire**, una app gratis para organizar tu día y compartirlo con tus amigos.
- 🛠️ **Uso a diario:** **Java**, **Spring Boot**, **Python**, **FastAPI**, **TypeScript** y **React**.
- 🌱 **Aprendiendo:** **Tauri**, **Supabase** y análisis de datos con **R**.
- 💼 **Disponible** para proyectos colaborativos y desarrollo a medida.
